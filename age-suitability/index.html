Age Suitability

Gus is a Jellyfin client. Age appropriateness depends on the content available on the user's own Jellyfin server.

What Gus does

A Playa Named Gus connects users to Jellyfin servers they provide. Users access their own media libraries through the app.

What Gus does not do

  • Gus does not host, curate, sell, or distribute media.
  • Gus does not provide unrestricted web access.
  • Gus does not include chat, messaging, advertising, gambling, contests, loot boxes, or monetized chance mechanics.
  • Gus does not determine the maturity rating of every user's media library.

Content access

Age appropriateness depends on the libraries, metadata, and permissions configured on the user's Jellyfin server. The server owner controls which users can access which libraries and content.

Guidance for parents and guardians

Parents and guardians should manage access through Jellyfin user permissions, Jellyfin library restrictions, and Apple Screen Time. Review the connected server's content and user settings before giving a child access to the app.

App Review context

Because Gus can browse and play user-supplied media whose content is outside the app developer's control, the App Store age rating may reflect access to user-provided media rather than developer-hosted content.
