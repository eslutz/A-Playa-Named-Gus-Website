Support

Get help connecting to a Jellyfin server, playing media, using downloads, and reporting reproducible issues.

Contact

GitHub Issues are the primary support route because they make reproducible bugs easier to track.

Open a GitHub Issue

Email is also available at support@ericslutz.dev. Keep the subject prefix GUS SUPPORT so support mail is routed correctly.

Before reporting a bug

  • Confirm the Jellyfin server URL works in Safari on the same network.
  • Note the platform: iPhone, iPad, Apple TV, Apple Vision Pro, or Mac.
  • Include the app version, Jellyfin server version, and whether the server uses HTTP or HTTPS.
  • Describe the media type and playback path, but do not include private server URLs, passwords, tokens, or personal library screenshots.

FAQ

What do I need to use Gus?

You need access to a Jellyfin server. Gus is a client app and does not include hosted media or a hosted Jellyfin account.

Does Gus support Quick Connect?

Quick Connect support is part of the sign-in flow when the connected Jellyfin server supports it.

Why can local server discovery ask for network permission?

Find Local Servers uses the local network to discover Jellyfin servers. Manual URL entry remains available if you do not want to use discovery.

Can I use an HTTP server?

Self-hosted Jellyfin servers often use HTTP on trusted local networks. For remote access, use HTTPS and server configuration appropriate for your network.

Why does playback fail for some files?

Playback depends on the media, Jellyfin server capabilities, network conditions, and AVKit support on the current Apple platform. If a file fails, include format details and whether it direct-plays or transcodes on the server.

Where are downloads available?

Downloads are available on iPhone, iPad, Mac, and Apple Vision Pro where supported by the app and server. Apple TV streams only.

What is Gus Cinema?

Gus Cinema is the Apple Vision Pro immersive playback path for supported scenarios. Availability depends on platform support, media format, and the current release state.
